PINA QUICKCONVERT — VERSION 1

Open index.html in a desktop browser for immediate use.

To install as an app on Windows and iPhone, host all four app files together on an HTTPS website (e.g., GitHub Pages). Then:
Windows Edge/Chrome: Open the site, use browser menu > Apps > Install this site as an app (Edge) or Install page as app (Chrome).
iPhone Safari: Open the site, tap Share > Add to Home Screen > Add.

Once opened online, the service worker caches files for offline use. An HTTPS origin (or localhost) is required for installation/offline caching. Opening index.html as a local file works as a calculator but cannot enable offline app installation.
